# Provenance

Woodcock is written from public scientific publications (as specifications) and
from the public APIs of MLX and mlx-lm. Nothing in this file is a statement of
legal clearance or of non-infringement.

How this repository started: see [`CARRYOVER.md`](../CARRYOVER.md).

## 1. Rules for contributions

* Use public sources only: arXiv papers and public web pages, cited per
  statement in the design notes.
* Do not read, copy or translate source code of other speculative-decoding
  projects whose license is not compatible with MIT, and do not use their weights.
* Record every new source in section 2.
* Do not consult the archived internal prototype for development. Implement
  any previously omitted functionality here from cited public specifications.
* Re-measure benchmark results with this code base before publishing them.

| Speculative decoding cost model (Leviathan et al. 2023) | arXiv:2211.17192 | expected tokens per round (Eq. 1), walltime factor (Thm. 3.8), choice of draft length (§3.5) |

(MIT) were read for API correctness.
